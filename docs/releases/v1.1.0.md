Game Pause 1.1.0 新增可配置的更新网络线路，并统一了设置窗口视觉。

### 主要更新

- 支持保存多条 GitHub 加速地址，并按优先级从 10 到 1 依次尝试。
- 内置不可删除的 GitHub 直连线路；直连和加速线路均可设为 0 禁用。
- 支持独立 HTTP 网络代理，同时作用于更新清单和安装包下载。
- GitHub 加速地址与 HTTP 网络代理可组合使用，配置保存在 `ui-settings.json`。
- 设置窗口新增“网络与更新”页，并统一页签、表格、按钮和选中状态样式。
- 兼容 1.0.0 的旧配置文件；首次升级会自动补充 GitHub 直连线路。

更新下载仍会校验 RSA 签名、SHA-256、程序集版本和安装包结构。代理只改变实际请求线路，不会绕过更新安全校验。本版本不保存代理账号或密码。

### 下载说明

推荐下载 `GamePause-1.1.0-Setup.exe` 安装版。安装版部署到 `Program Files`，支持自动更新。

`GamePause-1.1.0.zip` 是免安装版本，可直接解压运行，但出于安全原因不允许自动覆盖更新。

首次运行和安装均可能出现 Windows SmartScreen 提示，因为当前版本尚未使用商业代码签名证书。
