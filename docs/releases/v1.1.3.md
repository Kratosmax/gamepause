Game Pause 1.1.3 改进普通用户启动时的管理员权限引导，并修正设置保存后的反馈文案。

## 主要变化

- 启动时显式检查管理员权限。权限不足时提供“以管理员身份启动”和“取消”，确认后通过 Windows 用户账户控制重新启动。
- 提权取消或失败时安全退出，不再让程序以权限不足状态继续运行。
- 权限检查发生在单实例锁和更新收尾之前，避免普通权限进程阻挡管理员实例。
- 设置保存反馈按实际修改内容显示；仅修改代理时显示“网络与更新设置已保存”。
- 只修改网络设置时不再重复注销和注册全局快捷键。

## 下载选择

- `GamePause-1.1.3-Full-Setup.exe`：推荐安装版，内置 .NET 8 和全部框架语言资源。
- `GamePause-1.1.3-Lite-Setup.exe`：精简安装版，需要自行安装 .NET 8 Desktop Runtime x64。
- `GamePause-1.1.3-Full.zip`：内置运行时的免安装版。
- `GamePause-1.1.3-Lite.zip`：体积最小的免安装版，需要自行安装 .NET 8 Desktop Runtime x64。
