Game Pause 1.1.2 重点增强进程暂停、异常恢复和自动更新稳定性，并提供 Full/Lite 四种发行包。

### 主要更新

- 暂停和恢复前使用同一 Windows 进程句柄核验 PID 与启动时间，避免 PID 复用时操作错误进程。
- 更新器收尾失败不再阻止新版首次启动，损坏的待替换更新器会安全清理。
- 游戏档案主文件损坏时尝试临时文件和备份；全部损坏时阻止覆盖并提示用户。
- 更新下载增加 512 MB 上限和 30 秒传输停滞超时，启动后自动清理旧更新包。
- 主程序和更新器日志超过 5 MB 后轮转，卸载时清理开机启动计划任务。
- Full/Lite 使用独立更新通道；缺少通道标记的旧版本继续按 Full 更新。

### 下载说明

- `GamePause-1.1.2-Full-Setup.exe`：推荐安装版，内置 .NET 8 和全部框架语言资源。
- `GamePause-1.1.2-Lite-Setup.exe`：精简安装版，需要自行安装 .NET 8 Desktop Runtime x64。
- `GamePause-1.1.2-Full.zip`：内置运行时的免安装版。
- `GamePause-1.1.2-Lite.zip`：体积最小的免安装版，需要自行安装 .NET 8 Desktop Runtime x64。

.NET 8 Desktop Runtime x64 官方下载地址：

https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0/runtime?cid=getdotnetcore&runtime=windowsdesktop

不确定时请选择 Full 安装版。手动切换 Full/Lite 前应先卸载现有版本，用户档案不会随正常卸载删除。

首次运行和安装仍可能出现 Windows SmartScreen 提示，因为当前版本尚未使用商业代码签名证书。
