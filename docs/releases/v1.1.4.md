Game Pause 1.1.4 修复自动更新在读取压缩包程序集版本时失败的问题。

## 重要升级说明

0.9.1 至 1.1.3 的客户端会在自动更新替换前显示 `Stream must support read and seek operations`，因此无法依靠自动更新安装本版本。请从 GitHub Releases 手动下载并安装一次 1.1.4；用户档案和设置不会因此删除。升级完成后，后续自动更新恢复正常。

## 主要变化

- 主程序和独立更新器不再直接向 `PEReader` 传入不可定位的 ZIP 条目流。
- 校验前将程序集复制到可定位的受控缓冲区，同时保留包内程序集版本检查。
- PE 映像缓冲限制为 64 MB，避免异常压缩包造成无上限内存占用。
- 新增真实压缩 DLL 条目的回归测试，覆盖不可 Seek 的 ZIP 流和大小上限。

## 下载选择

- `GamePause-1.1.4-Full-Setup.exe`：推荐安装版，内置 .NET 8 和全部框架语言资源。
- `GamePause-1.1.4-Lite-Setup.exe`：精简安装版，需要自行安装 .NET 8 Desktop Runtime x64。
- `GamePause-1.1.4-Full.zip`：内置运行时的免安装版。
- `GamePause-1.1.4-Lite.zip`：体积最小的免安装版，需要自行安装 .NET 8 Desktop Runtime x64。
