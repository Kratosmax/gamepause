Game Pause 的第一个公开版本。

### 主要功能

- 批量暂停和恢复一个或多个进程树。
- 搜索、前台进程筛选与倒计时捕获。
- 游戏收藏、配置档案和按游戏自动规则。
- 托盘快速控制与自定义全局快捷键。
- 普通暂停、深度暂停和 Windows 整机休眠。
- 异常恢复记录、独立守护进程和紧急全部恢复。
- Windows 11 系统背景材质与 Windows 10 浅色回退主题。
- 签名更新清单、二次哈希校验、版本校验和失败回滚。

### 下载说明

推荐下载 `GamePause-1.0.0-Setup.exe` 安装版。安装版部署到 `Program Files`，支持后续自动更新。

`GamePause-1.0.0.zip` 是免安装版本，可直接解压运行，但出于安全原因不允许自动覆盖更新。

首次运行和安装均可能出现 Windows SmartScreen 提示，因为当前版本尚未使用商业代码签名证书。
