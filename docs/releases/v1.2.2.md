Game Pause 1.2.2 改进自动更新窗口，在同一界面中展示版本公告、真实下载进度、当前线路和校验状态，并支持安全取消下载。

## 主要变化

- 更新提示窗口使用独立、可滚动的版本公告区域，长公告和最小窗口尺寸下仍保留稳定的下载操作区。
- 下载时显示实际字节百分比、已下载大小和总大小；服务器未提供总大小时使用不确定进度，不伪造百分比。
- 显示当前下载 URL、线路序号和线路失败原因，切换备用线路时可直接看到当前状态。
- 明确显示 SHA-256、版本、Full/Lite 通道和包结构校验阶段，全部校验通过后才进入安装。
- 下载期间可取消；取消或线路失败会清理未完成的临时文件，不会修改当前安装目录。

## 升级说明

1.2.1 可以通过自动更新升级到 1.2.2。

0.9.1 至 1.2.0 仍无法依靠自身自动更新安装本版本：0.9.1 至 1.1.3 会在旧版压缩包预检阶段失败，1.1.4 至 1.2.0 的旧更新器会锁住自身依赖。请从 GitHub Releases 手动安装一次 1.2.1 或更高版本；用户档案和设置位于 `%LocalAppData%\GamePause`，正常覆盖安装不会删除。

## 下载选择

- `GamePause-1.2.2-Full-Setup.exe`：推荐安装版，内置 .NET 8 和全部框架语言资源。
- `GamePause-1.2.2-Lite-Setup.exe`：精简安装版，需要自行安装 .NET 8 Desktop Runtime x64。
- `GamePause-1.2.2-Full.zip`：内置运行时的免安装版。
- `GamePause-1.2.2-Lite.zip`：体积最小的免安装版，需要自行安装 .NET 8 Desktop Runtime x64。
