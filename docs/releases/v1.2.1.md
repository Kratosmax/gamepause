Game Pause 1.2.1 修复旧更新器锁住自身依赖导致自动替换和回滚失败的问题，并包含 1.2.0 的全部进程冻结安全改进。

## 重要升级说明

0.9.1 至 1.2.0 均无法依靠自身自动更新安装本版本：

- 0.9.1 至 1.1.3 会在旧版压缩包程序集预检阶段失败。
- 1.1.4 至 1.2.0 的旧更新器会锁住 `GamePause.Core.dll` 和 `GamePause.Updater.dll`，导致替换失败。

请从 GitHub Releases 手动下载并安装一次 1.2.1。用户档案和设置位于 `%LocalAppData%\GamePause`，正常覆盖安装不会删除。升级到 1.2.1 后，后续自动更新恢复正常。

## 主要变化

- 更新器先将现有文件原子改名到备份目录，再写入新版本，避免截断已加载的 DLL。
- 安装失败时将原文件改名恢复；新主程序等待旧更新器退出后替换 updater apphost 并清理备份。
- 新增锁定文件安装和回滚测试，覆盖更新器自身依赖仍被加载的场景。
- 冻结进程树时排除 `douyin_tray.exe`、Windows App Runtime DDLM 组件及其整个后代分支。
- Watchdog 在稳定暂停期间探测任务栏响应，连续两次无响应会自动恢复本程序记录的全部目标。
- 主程序与 Watchdog 使用跨进程互斥，避免并发修改暂停恢复记录。
- 设置中新增默认关闭的 Debug 模式，按需记录进程树、父子 PID、路径和安全排除详情。
- 主程序默认普通权限启动，仅在用户主动暂停遇到拒绝访问时询问提权；开机任务使用普通权限。
