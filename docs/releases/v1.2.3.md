# Game Pause 1.2.3

## 变更

- 启动时检测 Windows 是否启用系统休眠。
- 未启用休眠时隐藏“整机休眠”按钮，避免显示不可用功能。
- 点击整机休眠前再次检查休眠状态；系统运行期间关闭休眠时不会继续发起整机休眠。
- 记录启动时的休眠能力检测结果，便于诊断。

## 兼容性

- Windows 10/11 x64。
- Lite 版需要预先安装 .NET 8 Desktop Runtime x64；Full 版内置运行时。
- 用户数据和暂停恢复状态位置不变，升级不会删除 `%LocalAppData%\\GamePause`。

## 升级说明

1.2.2 用户可直接升级到 1.2.3。Full 和 Lite 仍使用独立更新通道，请保持安装包通道一致。
