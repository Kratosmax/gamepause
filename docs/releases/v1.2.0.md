Game Pause 1.2.0 优先修复冻结 PC 抖音时可能连带影响 Windows 桌面交互的问题，并改进诊断和权限体验。

> **已撤回为预发布版本：** 真实更新链验证发现旧更新器会锁住自身依赖，导致自动替换和回滚失败。请不要使用 1.2.0，改为手动安装 1.2.1 或更高版本。

## 主要变化

- 冻结进程树时排除 `douyin_tray.exe`、Windows App Runtime DDLM 组件及其整个后代分支，避免误冻结壳层辅助进程。
- 独立 Watchdog 在暂停会话稳定后持续探测任务栏响应；连续两次无响应会自动恢复本程序记录的全部目标。
- 主程序与 Watchdog 使用跨进程互斥串行化暂停、恢复和状态校验；Watchdog 恢复前会再次拒绝仍处于 `Planned` 或 `Suspending` 的事务。
- 设置中新增 Debug 模式开关。默认关闭；开启后记录进程树、父子 PID、程序路径和安全排除详情。
- 主程序默认以普通权限启动，不再每次启动都请求管理员权限。仅当用户主动暂停且 Windows 返回拒绝访问时才询问是否提权重启；取消后程序继续运行。
- 开机启动任务改为普通权限，受限目标仍按需提权。

## 仍需真机观察

本版本已根据实机日志确认旧版会把抖音托盘分支和 Windows App Runtime 生命周期组件纳入冻结范围，并已从暂停树中排除。由于不同抖音版本的进程结构可能变化，升级后如仍出现桌面卡顿，请开启设置中的 Debug 模式并保留 `%LocalAppData%\GamePause\game-pause.log`。

- `GamePause-1.2.0-Lite-Setup.exe`：精简安装版，需要自行安装 .NET 8 Desktop Runtime x64。
- `GamePause-1.2.0-Full.zip`：内置运行时的免安装版。
- `GamePause-1.2.0-Lite.zip`：体积最小的免安装版，需要自行安装 .NET 8 Desktop Runtime x64。
